# Learning notes

My own reference: written by me, for future me.

## How I use this

- **One file per topic**, e.g. `ai/ollama.md` or `frontend/react-state.md`.
- Copy [`_template.md`](_template.md) when starting a new topic.
- Write it **in my own words**, as if explaining it to someone else.
- Add a line to the topic table in that folder's README so I can find it later.
- New jargon goes in [`glossary.md`](glossary.md).
- Mistakes are worth writing down ("I tried X, it broke because Y").

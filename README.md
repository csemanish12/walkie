# Walkie

Push-to-talk for Claude. A personal tool to see what Claude (desktop app) is doing in each session, and talk to it by text or voice.
Runs fully locally on my Mac (M1, 16 GB).

Also a learning project for **AI** (local LLMs and voice models) and **frontend** (React).
